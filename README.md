# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe Game** created using **HTML, CSS, and JavaScript**.

## 📌 About the Project

This project is a classic Tic Tac Toe game where two players can play against each other.

- Player 1 uses **X**
- Player 2 uses **O**
- The first player to get three symbols in a row wins.
- The game can end in a draw if all boxes are filled.

## ✨ Features

- Two-player game
- X and O turns
- Winner detection
- Draw detection
- Reset/New Game option
- Simple and user-friendly interface
- Responsive game board

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 How to Play

1. Open `index.html` in your browser.
2. Player X starts the game.
3. Click on any empty box.
4. Players take turns placing X and O.
5. Get three matching symbols in a row, column, or diagonal to win.
6. Click the **Reset Game** button to start again.

## 🏆 Winning Conditions

A player wins when they get three X's or O's in:

- A horizontal row
- A vertical column
- A diagonal

Example:

X | X | X
--|---|--
O | O |
  |   |

Winner: **Player X 🎉**
